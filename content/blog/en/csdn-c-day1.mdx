Before setting up SSH remote control, I read many articles from other experts. The common solution was to add two files to the SD card, but after several attempts, I still struggled to connect the Raspberry Pi to my computer's hotspot. I later borrowed a classmate's monitor to identify the issue. This post covers the problems encountered during Ubuntu (ARM64) system deployment, SSH setup, and WiringPi installation on the Raspberry Pi, along with the resources I consulted and my final, personally verified solution. After successfully becoming a 'light-blinking master,' we complete the system download. Once system initialization is finished, you can check the Raspberry Pi's address via the computer's hotspot and configure Xshell according to the tutorial in the above documentation.
