This is not a 'luxury solution,' but an engineering exercise that puts budget, feasibility, and maintainability on the same table for discussion.

## Project Positioning

- Goal: Build a **low-cost** logistics vehicle capable of basic transport and path learning
- Language: C
- Repository: [github.com/TonyDDcui/Logistics-truck](https://github.com/TonyDDcui/Logistics-truck)

## What I Did (Brief Version)

- Split directories according to embedded engineering practices (BSP / DRIVERS / User, etc.)
- Advanced from 'functionally runs' to 'structurally readable and portable'
- Reserved space for future iterations: sensors, control strategies, path logic
